ניהול וסינון משתמשים (סטודנטים מול סגל)

המערכת מזהה אוטומטית סטודנטים רשומים מתוך אירועי התפקיד הוקצה (role id 5) ומסננת אנשי סגל ומערכת (כגון ישי מור, גדי מלכה, ראשים מכלול). ניתן לסמן או להסיר משתמשים ידנית:

איך להעלות ולהריץ את האפליקציה ב-GitHub Pages?

יתרון אבטחה ופרטיות: האפליקציה בנויה כקובץ index.html יחיד הפועל כולו בדפדפן (Client-Side). כשמעלים קובץ CSV של Moodle לדשבורד, הנתונים אינם נשלחים לשום שרת חיצוני אלא מעובדים בזיכרון הדפדפן בלבד.
  1. שמירת הקובץ: שמור קובץ זה בשם index.html במחשב שלך.
  2. יצירת מאגר (Repository) ב-GitHub:

    היכנס לחשבון ה-GitHub שלך, לחץ על New Repository, תן לו שם (למשל moodle-course-dashboard) וצור אותו.

  3. העלאת הקובץ:

    לחץ על Add file → Upload files, גרור את הקובץ index.html ולחץ על Commit changes.

  4. הפעלת GitHub Pages:

    עבור ללשונית Settings → Pages בתפריט הצד. תחת Branch בחר ב-main (או master) ולחץ על Save.

  5. קבלת קישור לאתר החי:

    תוך כדקה יופיע קישור קבוע לאפליקציה שלך (לדוגמה: https://username.github.io/moodle-course-dashboard/) שממנו תוכל לטעון בכל עת קבצי CSV חדשים מ-Moodle!
